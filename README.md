# Coffee Rush ☕

**Жанр:** Аркада-симулятор офисного выживания  
**Платформа:** Windows (Windows Forms, C#)  
**Сеттинг:** Офис, вид сверху

## Сюжет
Ты — офисный работник. Задача — выжить на работе, выполняя задания, пить кофе и избегать начальника.

## Геймплей
- Выполняй рабочие задания (клик + удержание)
- Пей кофе и ешь (восстанавливают энергию)
- Прячься в кабинке от начальника
- Не дай энергии упасть до нуля!

## Структура проекта
```
CoffeeRush/
├── Assets/      # Картинки, звуки
├── Forms/       # Окна (MainMenu, Game, GameOver)
├── Models/      # Игровые объекты
├── Services/    # Логика игры
└── Utils/       # Вспомогательные классы
```

## Управление
- Мышь: клики по объектам
- SPACE: быстро спрятаться в кабинку
